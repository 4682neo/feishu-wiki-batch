# feishu-wiki-downloader

飞书 Wiki 批量下载用户脚本，基于 Tampermonkey / ScriptCat 运行，直接在飞书 Wiki 页面中批量导出文档到本地。

## 功能

- 批量下载飞书 Wiki 节点下的文档
- 按节点目录树遍历下载
- 支持单个文档下载
- 在飞书页面内直接运行，无需命令行环境

## 安装

1. 安装用户脚本管理器（任选其一）：
   - [Tampermonkey](https://www.tampermonkey.net/)（油猴）
   - [ScriptCat](https://scriptcat.org/)（脚本猫）
2. 安装本仓库中的用户脚本：
   - 打开脚本文件，复制全部内容，在脚本管理器中新建脚本并粘贴保存；或
   - 通过脚本管理器直接导入 `.js` 文件
3. 在脚本管理器中确认该脚本已启用。

## 使用方法

1. 登录飞书，打开目标 Wiki 知识库页面（`my.feishu.cn`）。
2. 进入需要下载的 Wiki 节点或文档页面。
3. 脚本会在页面上注入操作入口（按钮 / 面板），按提示选择批量下载或单篇下载。
4. 下载的文件会保存到浏览器默认下载目录。

## 配置说明

脚本运行前可能需要以下信息（视脚本实现而定）：

| 配置项 | 说明 |
| --- | --- |
| `space_id` | 飞书 Wiki 知识库的空间 ID，可从 Wiki 页面 URL 中获取 |
| 下载范围 | 当前节点 / 整个目录树 / 单篇文档 |
| 请求间隔 | 批量下载时的请求间隔，避免触发频率限制 |

## 兼容性

- Tampermonkey（Chrome / Edge / Firefox）
- ScriptCat（Chrome / Edge）
- 需已登录飞书账号，并具备目标 Wiki 的访问权限

## 注意事项

- 请遵守飞书服务条款，仅下载你有权限访问的内容。
- 批量下载请控制请求频率，避免对服务造成压力。
- 脚本依赖飞书页面结构，飞书前端更新后可能失效，需自行调整。
